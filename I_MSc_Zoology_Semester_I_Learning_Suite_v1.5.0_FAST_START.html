Release integrity

Each source application is isolated in a fresh frame. Embedded subject routes replace the frame's current history entry rather than creating nested Back-stack entries.

Navigation hardening: SERICA route links use same-document replace routing inside the trusted frame; the master owns one Back-history state. Closing a module removes the entire frame before its Blob URL is revoked, preventing stale hidden frames and white-screen restoration.
