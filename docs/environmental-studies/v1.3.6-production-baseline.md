## Production-only corrections permitted

The educational payload is frozen. The production workflow is permitted to patch only the extracted build tree, after the frozen source has passed its original source checks. The production patch is limited to:

1. secure environment-backed release signing configuration;
2. explicit APK Signature Scheme v2 and v3;
3. `debuggable false` for release;
4. `android:allowBackup="false"`;
5. removal of active `dataExtractionRules` and `fullBackupContent` manifest references.

The source ZIP itself must remain byte-identical. No lesson, Tamil/English text, MCQ, catalog entry, SVG/figure, reader script, CSS, or bundled privacy page may be changed by the release correction.

## Repository-branch exception

This repository's default `main` branch does not contain the Environmental Studies Android source archive. The app's authoritative source is maintained on dedicated Environmental Studies branches. Moving the complete Android history into `main` would be an unrelated repository migration and would violate the minimum-change rule.

Therefore the production gate uses a dedicated authoritative branch:

`environmental-studies-v1.3.6-production`

The signed-release job is permitted only from that branch. This is an explicit repository-architecture exception to a generic `main`-branch release rule; it does not weaken any source, signing, or binary verification gate.

## Device QA

CI/static verification cannot certify handset behavior. The exact signed APK produced by the production workflow remains `DEVICE QA: NOT PERFORMED` until its SHA-256 is tested on a real Android device.
